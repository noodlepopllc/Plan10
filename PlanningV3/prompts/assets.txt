Your job is to convert the CHARACTER BIOGRAPHY BLOCK into the `characters[]`
portion of the asset registry AND convert the LOCATION BLOCK into the
`locations[]` portion of the asset registry.

You MUST ignore all scene/shot information during character and location extraction.
Later, a separate pass will process SHOTS to generate the `scenes[]` portion.

Output ONLY valid JSON.

============================================================
LAYER 1 — HARD CONSTRAINTS (CANNOT BE VIOLATED)
============================================================

1. VOICE DESIGNER RULE (STRICT)
Voice format (exact tokens only):
"gender, age, pitch[, accent][, whisper]"

- gender: male | female
- age: child | teenager | young adult | middle-aged | elderly
- pitch: very low pitch | low pitch | moderate pitch | high pitch | very high pitch
- accent: ONLY if explicitly mentioned
- whisper: ONLY if explicitly mentioned

NEVER invent optional tokens.

2. REQUIRED IDENTITY FIELDS (MANDATORY)
appearance_prompt MUST include:
- gender
- hair silhouette (short/medium/long + straight/wavy/curly/tied-back/bob)
- hair color
- base clothing (1–2 items)
- ethnicity ONLY if explicitly mentioned

3. APPEARANCE FORMAT
appearance_prompt MUST be 10–20 words, visually essential only.
NO environment, NO props, NO lore, NO emotion.

Android traits = surface materials (polymer, alloy, metallic).
Animorphic traits = costume elements (ears, tail, gloves).

4. CHARACTER DIFFERENTIATION RULE
Characters MUST differ in:
- body type
- material/theme
- color palette
- clothing category
- hair silhouette OR hair color OR accessory

5. BIOGRAPHY PRESERVATION RULE
If biography specifies ethnicity, clothing, android type, hair, etc.,
you MUST preserve and compress it into appearance_prompt.

============================================================
LAYER 1B — LOCATION + ZONE EXTRACTION RULES (CORRECTED)
============================================================

You MUST extract every location and every zone exactly as written in the LOCATION BLOCK.

For each location:
- `name` MUST match the block exactly.
- `slug` MUST be lowercase with underscores.
- `description` MUST be copied EXACTLY as written (NO summarization).
- `zones[]` MUST include EVERY zone under that location.
- Each zone MUST include:
    • zone_name (exact heading)
    • description (the full text under that zone)
- `notable_details[]` MUST copy the numbered list EXACTLY as written.

You MUST NOT:
- invent locations
- invent zones
- merge zones
- compress descriptions
- drop details
