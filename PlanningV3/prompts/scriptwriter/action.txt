SECTION 1 — ACTION BEATS (VARIABLE LENGTH)

Your job is to convert the NARRATED MACRO STORY into a sequence of MACRO ACTION
BEATS. Each beat represents one meaningful physical event that would justify a
cinematic shot or anime cut.

This is a direct extractor, not a generator.

------------------------------------------------------------
REQUIRED BEHAVIOR
------------------------------------------------------------

✔ 1. Variable number of beats
You MUST produce one ACTION BEAT per macro event in the narration.
Do NOT force a fixed number.

Most scenes will produce 3–8 beats.

✔ 2. Each ACTION BEAT MUST include:
- the zone where the event occurs (if stated)
- the characters present at the start of the event
- the macro‑level physical action that occurs
- any character entering or leaving the zone (only if explicitly stated)
- any threshold crossing (only if explicitly stated)
- any dialog hint (if the narration includes one), expressed as an ACTION

✔ 3. Dialog as ACTIONS
If the narration includes a dialog hint:
- you MUST include it as part of the ACTION BEAT
- you MUST phrase it as a physical action, e.g.:

  “Character speaks, asking whether she loves him.”
  “Character responds, stating her programmed answer.”

- you MUST NOT quote the dialog line
- you MUST NOT invent new meaning

✔ 4. Macro physical actions ONLY
Each beat MUST describe one meaningful physical event such as:
- approaching or withdrawing
- turning toward or away
- initiating or ending an interaction
- taking a new physical position
- performing a significant gesture
- shifting the physical dynamic of the scene
- speaking (as an action)

You MUST NOT include micro‑actions such as:
- tiny weight shifts
- eye darts
- hair movement
- subtle twitches
- micro‑gestures or micro‑posture changes

✔ 5. No invention
You MUST NOT add:
- new props
- new zones
- new characters
- new blocking not implied
- new story events

✔ 6. No narrative prose
You MUST NOT include:
- metaphor
- emotion
- sensory detail
- internal thoughts
- flourish

✔ 7. No multi‑step chains
Each beat describes ONE macro event, not a sequence of future actions.

✔ 8. No repetition
Each beat must add new physical information.

------------------------------------------------------------
OUTPUT FORMAT
------------------------------------------------------------

SECTION 1 — ACTION BEATS

[Beat 1]

[Beat 2]

[Beat 3]
