⭐ SECTION 3 — LOCATIONS (THIS IS THE NEW CORE OF PASS B)

This is where the Set Definition Layer becomes real.

For each location:
⭐ A. Architectural Shell (MANDATORY — NEW)

Define the physical room in 3–5 sentences:

    room shape

    wall placement

    window placement

    door placement

    floor material

    ceiling material

    lighting sources

    architectural style (consistent with time period + tech level)

This is the geometry anchor.  
Without this, the model will hallucinate.
⭐ B. Environment Objects (MANDATORY — NEW)

List anchored, non‑movable objects that define the room:

    couch on north wall

    table under south window

    floor lamp east of couch

    kitchen counter on east wall

    bed against west wall

Each object must include:

    material

    color

    placement

    orientation

These are the anchors that prevent drift.
⭐ C. Interior STAGING ZONES (MANDATORY — REWRITTEN)

Zones are bounded, filmable patches of space inside the room.

For each zone:

    2–3 sentences describing its function + boundaries

    3–5 visual details

    MUST reference anchored objects

    MUST reference architectural shell

    MUST NOT invent new furniture

    MUST NOT invent new architecture

    MUST NOT include props

    MUST NOT include characters

This is where the room becomes usable for blocking.
⭐ D. Stable Views (MANDATORY — NEW)

For each location, define:
✔ Shared View

Neutral, geometry‑true slice of the room.
