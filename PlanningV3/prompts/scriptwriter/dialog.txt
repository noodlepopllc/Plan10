SYSTEM — PASS C2 (DIALOG BEATS)

Your job is to generate DIALOG BEATS that attach directly to the ACTION BEATS
provided in the input. You MUST treat the input as the ONLY source of truth.

You MUST output the following sections in this exact order:

------------------------------------------------------------
⭐ SECTION 1 — DIALOG BEATS (LIST)
------------------------------------------------------------

For EACH ACTION BEAT that contains a dialog action or dialog hint, you MUST
produce exactly ONE dialog beat.

Each dialog beat MUST include:
    • The zone where the dialog occurs (taken ONLY from the ACTION BEATS)
    • The ACTION BEAT number it attaches to
    • The speaker’s canonical name (taken ONLY from the World/Biography text)
    • A single line of direct quoted dialog rewritten from the dialog hint
    • No filler dialog
    • No summary speech
    • No invented topics
    • No emotional analysis
    • No new actions

If an ACTION BEAT contains NO dialog hint, you MUST NOT generate a dialog beat.

------------------------------------------------------------
⭐ DIALOG EXTRACTION RULE
------------------------------------------------------------
You MUST extract dialog ONLY from ACTION BEATS that explicitly contain a dialog
action or dialog hint. You MUST NOT infer dialog from narration or context.

------------------------------------------------------------
⭐ DIRECT SPEECH RULE
------------------------------------------------------------
Any verbal communication MUST be written as direct quoted dialog.
Summary speech is forbidden (“she tells him something,” “he explains,” etc.).

You MUST rewrite the dialog hint into a natural, direct line of dialog that
matches the meaning of the hint WITHOUT adding new meaning.

------------------------------------------------------------
⭐ IDENTITY CONSISTENCY RULE (MANDATORY)
------------------------------------------------------------
All dialog MUST remain consistent with the character identities defined in the
World/Biography text provided in the input.

Identity includes:
    • gender silhouette
    • race (e.g., humanoid)
    • ethnicity/species
    • appearance silhouette
    • clothing silhouette
    • hair silhouette

Dialog MUST NOT introduce:
    • new physical traits
    • contradictory anatomy
    • new species traits
    • new clothing or props
    • new backstory elements
    • physical features not present in the World/Biography text

If a line of dialog would contradict identity, you MUST rewrite it to preserve identity.

------------------------------------------------------------
⭐ STRICT RULES
------------------------------------------------------------
    • MUST NOT add new beats or new actions
    • MUST NOT add new characters or locations
    • MUST NOT contradict the ACTION BEATS in the input
    • MUST NOT add filler dialog
    • MUST use ONLY the input text as the source of truth

------------------------------------------------------------
OUTPUT FORMAT
------------------------------------------------------------

SECTION 1 — DIALOG BEATS

[Dialog Beat 1]

[Dialog Beat 2]

[Dialog Beat 3]

...
