═══════════════════════════════════════════════════════════════
CONVERSION RULES
═══════════════════════════════════════════════════════════════

1. TAG LINE (First Line)
   - Extract or generate a one-sentence hook from the prose
   - Format: >> Tag line text here

2. SCENE HEADING
   - Format: INT./EXT. LOCATION - TIME
   - Use EXACT location name from world model
   - Time: DAY/NIGHT/CONTINUOUS (infer from context)

3. CHARACTER INTRODUCTION
   - First appearance: CHARACTER NAME (key visual traits from world model)
   - All caps for character names
   - Use ONLY details from world model - no hallucination
   - Follow with a brief action establishing their position

4. SCENE DESCRIPTION
   - 1-2 lines describing atmosphere/sensory details
   - Present tense, visual only

5. COLD OPEN END MARKER
   - Place after character intros and scene description
   - Format: COLD OPEN END

6. BEAT FORMAT (CRITICAL)
   
   Every beat is separated by blank lines. Use exactly these three formats:
   
   ─── ACTION-ONLY (no dialog) ───
   [ZONE: Zone Name]
   
   CHARACTER NAME action description ending with period.
   
   ─── DIALOG-ONLY (no action) ───
   [ZONE: Zone Name]
   
   CHARACTER NAME
   Dialog text without quotes.
   
   ─── ACTION + DIALOG (combined) ───
   [ZONE: Zone Name]
   
   CHARACTER NAME (action description in parentheses)
   Dialog text without quotes.
   
   RULES:
   - Blank line after every [ZONE: marker]
   - Blank line after every beat (before next [ZONE: marker])
   - Character name in ALL CAPS
   - Action-only: full sentence ending with period
   - Action+dialog: action in parentheses on SAME LINE as character name
   - Dialog-only: name on its own line, dialog on next line
   - Dialog: NO quotes, NO "he said/she said" tags
   - Present tense only
   - Visual/observable actions only (no internal thoughts)

7. ZONE TRACKING (CRITICAL)
   - Add [ZONE: Exact Zone Name] before EVERY beat
   - Use ONLY zone names from AVAILABLE ZONES list above
   - Repeat marker for every beat, even if zone doesn't change
   - This is required for parsing
