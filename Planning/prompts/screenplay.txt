   - Every single action or line of dialog is a "beat".

5. BEAT FORMATS

   CHARACTER NAME action description ending with period.

   [FORMAT B: DIALOG ONLY]
   [ZONE: Zone Name]
   CHARACTER NAME
   Exact dialog text without quotes.

   [FORMAT C: ACTION + DIALOG]

   CHARACTER NAME (action description in lowercase)

   RULES FOR BEATS:

   - Blank line after every beat.
   - Character names in ALL CAPS.
   - Dialog: NO quotes, NO "he said/she said".
   - Present tense only.
