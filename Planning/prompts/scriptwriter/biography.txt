- FILMABLE & PHYSICAL: All descriptions must be physical, deterministic, and renderable by a video model. No abstract emotions, no cinematic camera language (e.g., no "dramatic lighting", use "light originates from north window").

⭐ THREE-TIER ARCHITECTURE
The world model has three hierarchical levels:

1. LOCATIONS: Top-level physical spaces (e.g., "The Gilded Tankard", "Parking Lot", "Back Alley")
2. ZONES: Physical sub-areas within a location (e.g., "Corner Table", "Bar Counter", "Kitchen")
3. BACKDROPS: Camera viewpoints within a zone (e.g., "Corner Table - Fireplace View", "Corner Table - Two-Shot")

RULES:
- Each location contains 2-4 zones (physical sub-areas)
- Each zone contains 2-4 backdrops (camera viewpoints)
- Backdrops define what the camera sees when filming in that zone
- Two-shot backdrops are shared when both characters are visible
- Solo backdrops are character-specific when camera films one character

⭐ ZONE DEFINITION (PHYSICAL SPACE)
A zone is a physical sub-area within a location. It describes WHERE characters stand, not what the camera sees.

Zone naming: Use functional area names (e.g., "Corner Table", "Bar Counter", "Kitchen Pass-Through")

Zone definition must describe:
- What part of the location this area occupies
- Fixed physical features (furniture, structures)
- Spatial relationship to other zones
- Functional purpose (eating, serving, waiting)

❌ FORBIDDEN: Including camera angles, viewpoints, or backdrop descriptions in zone_definition
✅ REQUIRED: Describing physical space only

⭐ BACKDROP DEFINITION (CAMERA VIEW)
A backdrop is a camera viewpoint within a zone. It describes WHAT THE CAMERA SEES when filming in that zone.

Backdrop naming format:
- Two-shot: "[Zone Name] - Two-Shot"
- Solo: "[Zone Name] - [Character Name]'s View"

Examples:
- "Corner Table - Two-Shot" (camera sees both characters)
- "Corner Table - Maya's View" (camera positioned behind Maya, sees what's behind her)
- "Corner Table - Elias's View" (camera positioned behind Elias, sees what's behind him)

Backdrop definition must describe:
- Which character this backdrop is for (solo) or that it's for both (two_shot)
- What background elements are visible behind the character(s)
- What foreground elements frame the shot
- Camera positioning relative to zone and character

REQUIRED BACKDROPS PER ZONE:
1. At least 1 two-shot backdrop (for when both characters are visible)
2. At least 1 solo backdrop PER CHARACTER (each character must have their own backdrop)

Example for 2-character scene:
- Zone: "Corner Table"
- Backdrops:
  - "Corner Table - Two-Shot" (both visible)
  - "Corner Table - Maya's View" (solo, camera behind Maya)
  - "Corner Table - Elias's View" (solo, camera behind Elias)

⭐ VALIDATION CHECK

⭐ GLOBAL LIGHTING STATE (CRITICAL FOR CONTINUITY)
The setting MUST establish a single, fixed time of day and lighting condition that applies to ALL backdrops in ALL zones.

In the setting.room_form field, you MUST specify:
- Exact time of day (e.g., "mid-morning", "late afternoon", "night")
- Sky condition (e.g., "clear blue sky", "overcast grey", "stormy dark clouds")
- Sun position (e.g., "sun high overhead", "low golden sun from west", "no sun visible")
- External light color (e.g., "warm golden daylight", "cool blue twilight", "dark night with no natural light")

ALL backdrops MUST reference this same lighting state when describing windows or exterior views.

Example:
If setting says "late afternoon with low golden sun from west", then:
- Every window view MUST show "low golden sunlight from west"
- Every window view MUST show "warm orange sky"
- NO backdrop can show "bright midday sun" or "dark night sky"

⭐ WINDOW VIEW CONSISTENCY
For any backdrop that includes windows or exterior views:
- visible_background_elements MUST include sky condition matching global lighting
- backdrop_definition MUST describe exterior lighting consistent with time of day
- If time is "night", windows show dark sky, no sunlight
- If time is "day", windows show sky color matching global state

❌ FORBIDDEN: Inconsistent sky/lighting across backdrops
✅ REQUIRED: All windows show same time of day and sky condition
