🎬 CINEMATIC ACTION BEATS EXTRACTOR SPEC (REVISED)
CORE RULES

    NEVER summarize.

    NEVER paraphrase dialog.

    ALWAYS extract spoken lines EXACTLY as written.

    EVERY beat must contain:

        zone

        actions (atomic physical actions WITH spatial qualifiers)

        dialog (list of {speaker, line} only)

        posture (per character)

        facial_state (per character, per beat)

        head_gesture (per character, per beat)

        tone (per character, per beat)

ACTIONS

    Must be atomic but complete: one physical action, with subject, verb, object, and spatial qualifier.

    Preserve all prepositional phrases (pose geometry).

    Do not invent or synthesize actions.

    Idle/filler actions only allowed if beat already contains meaningful interaction.

DIALOG

    Extract exact quoted lines.

    No narration, no paraphrase, no metadata inside dialog.

    If no quotes, reconstruct literal implied line (no summary).

    Dialog entries are speech only:
    

    dialog:
      - speaker: Elara
        line: "Nadia! Wait!"
      - speaker: Nadia
        line: null

PERFORMANCE METADATA (PER BEAT)

    Posture: per character, per beat.

    Facial_state: per character, per beat.

    Head_gesture: per character, per beat.

    Tone: per character, per beat.

These are not attached to dialog lines. They appear once per beat, covering all dialog and actions in that beat.
PRONOUN ANNOTATION PRESERVATION

    If narrative uses he (Marcus) or she (Elara), preserve exactly in actions, dialog, posture, facial_state, tone, head_gesture.

    Do not normalize or replace pronouns.

BEATS WITHOUT ACTIONS

    A beat may contain only dialog, posture, or emotional exchange.

    Do not invent filler actions to “complete” a beat.

OUTPUT FORMAT


[Beat N]
zone: <zone name>
actions:
  - <character> <atomic action with spatial qualifier>
  - <character> <atomic action with spatial qualifier>
dialog:
  - speaker: <name>
    line: "<exact dialog>"
posture:
  - <character>: <posture>
facial_state:
  - <character>: <facial_state>
head_gesture:
  - <character>: <head_gesture or null>
tone:
  - <character>: <tone>

EXAMPLE


[Beat 5]
zone: Seated Dining Position
actions:
  - Elara stands up
  - Elara leans over table surface
  - Elara blocks Nadia's view
  - Nadia flushes
dialog:
  - speaker: Elara
    line: "Now, tell me about your own adventures! Have you ever faced a dragon? Or maybe a bandit lord?"
  - speaker: Elara
    line: "But you're so quiet! It's like you're hiding something."
  - speaker: Nadia
    line: "I'm not hiding anything,"
  - speaker: Nadia
    line: "I just need to finish my shift."
posture:
  - Elara: standing
  - Nadia: standing
facial_state:
  - Elara: confused
  - Nadia: flushed
head_gesture:
  - Elara: null
  - Nadia: null
tone:
  - Elara: neutral
  - Nadia: sharper
