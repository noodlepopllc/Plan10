CONTINUITY RULES (CRITICAL)
------------------------------------------------------------

You MUST analyze the actions in EACH beat and enforce these rules:

1) VISIBILITY RULE  
   If an object would reasonably be visible during EVERY action in the beat,
   then it MUST be mentioned in the FIRST action of the beat.

2) LEGITIMATE INTRODUCTION  
   If an action introduces an object FROM A CONTAINER  
   (e.g., “pulls X from pocket”, “draws X from belt”, “takes X from satchel”),  
   then the object is allowed to appear mid‑beat.

3) VISIBLE‑ALL‑BEAT OBJECTS  
   If an action uses an object that is carried openly, held, worn, or otherwise visible  
   (e.g., “carries a tankard of ale”, “holds a staff”, “grips a sword”),  
   and there is NO container phrase,  
   then the object is considered visible for the entire beat.

4) TELEPORTATION DETECTION  
   If an action uses an object that:
     • was NOT introduced from a container in this beat, AND
     • was NOT mentioned in the first action,
   then this is a teleportation error.
   Add a string description to continuity.teleportation_flags.

1. DO NOT change the text of any action.

   b) Container‑based introductions SHOULD appear before object usage.
   c) Visible‑all‑beat object actions SHOULD appear after pose actions.

4. If reordering cannot fix teleportation without changing text,
   leave the actions as‑is and ONLY flag the issue.
